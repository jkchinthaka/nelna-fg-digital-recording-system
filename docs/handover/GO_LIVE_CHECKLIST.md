# Go-live checklist

None of these boxes may be ticked by software. Owners tick them in writing.

- [ ] Formal UAT executed with named testers (`UAT_PLAN.md`)
- [ ] Business approval of digitalized source forms
- [ ] Official org/site/shift/product values loaded
- [ ] Named role assignments; no shared accounts
- [ ] SoD policy evidenced
- [ ] Production configuration reviewed (TLS, SMTP, object storage)
- [ ] Security review accepted
- [ ] Non-production restore drill accepted; production backup owner named
- [ ] Bileeta/ERP live calls remain off until contract + credentials approved
- [ ] Written go-live approval

Until every item is evidenced, the system is **not production ready**.
